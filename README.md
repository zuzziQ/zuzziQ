## 🚀 Core Engineering Competencies

### 🤖 Autonomous Multi-Agent Systems & MCP
- **Agent Orchestration**: Building specialized sub-agent swarms (`@BE`, `@FE`, `@QA`, `@Ops`, `@Psych`) with isolated scopes, minimal context leakage, and strict handoff budgets.
- **Model Context Protocol (MCP)**: Architecting custom MCP servers exposing database schemas, code graphs, and external tools to LLMs for deterministic tool execution.
- **Hierarchical Memory**: Implementing tiered memory systems using **Letta (MemGPT)** — archival memory, core identity blocks, and sliding context windows.
- **Defensive LLM Engineering**: Resilient JSON parsing, schema enforcement, rate-limit hedging, and multi-model fallback routines (Gemini Pro/Flash, Claude 3.5 Sonnet, GPT-4o).

### ⚡ Enterprise Workflow Automation
- **n8n & Webhooks**: Designing high-reliability visual & fair-code automation pipelines connecting CRMs, ERPs, and project trackers.
- **Natural Language Task Dispatchers**: Engineering asynchronous Telegram bot pipelines parsing natural language commands into structured issues via Plane.so and Google Sheets API.
- **Bi-directional State Machines**: Implementing multi-tier review loops (`Backlog` ➔ `In Progress` ➔ `In Review` ➔ `Done`) with automatic submission diffing and reviewer notifications.

### 🌐 Distributed Backend & High-Throughput Infrastructure
- **Microservices Stack**: Fastify REST APIs backed by a Go Gateway (`storymee-hub` on port 5100) with strict route prefixing and zero external port leakage.
- **Event Streaming**: NATS JetStream message brokers and Redis Pub/Sub for sub-millisecond asynchronous job dispatching.
- **Database Architecture**: PostgreSQL with PgBouncer connection pooling, Prisma ORM SSOT schemas, and zero-downtime migrations.
- **Cloud & Edge**: Cloudflare R2 object storage, Cloudflare Zero Trust Tunnels, Dockerized services, and automated CI/CD runners.

### 🎨 Modern Frontend Architecture
- **Next.js 16 & Turbopack**: Server Actions, React Server Components (RSC), App Router, dynamic streaming, and zero-layout-shift design.
- **Dark Glass Design Tokens**: High-density enterprise SaaS interfaces, Framer Motion micro-interactions, responsive grids, and biometric attendance visualizations.
